# Student Management System

A simple console-based Student Management System developed using Python.

## 📌 Project Description

The Student Management System is a Python-based application that allows users to manage student records easily through a menu-driven console interface.

The system provides basic operations such as adding, viewing, searching, updating, and deleting student information.

## ✨ Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student
- ✏️ Update Student
- 🗑️ Delete Student
- 🚪 Exit the Application

## 🛠️ Technologies Used

- Python
- VS Code
- GitHub
